# Integration
The build ships as community3d/ (city3d.js + models/ + index.html standalone demo).
On any page: add <div id="city3d-root"></div> sized by CSS, then import community3d/city3d.js (module). window.City3D.instance exposes setProgress(p 0..1) for the standalone 4-stage timeline, or setLift('market'|'communityCenter'|'streetLamps', 0..1) for page-driven sequencing, activeFeature() + onFeatureChange(cb) for external copy sync. Canvas is transparent — set the page background. Labels are NOT baked into the canvas (the host page owns copy). No scroll hijacking: the host page computes progress from its own scroll and calls the API.
Framer/iframe: host the folder statically and embed community3d/index.html in an iframe (dark background, no nested scroll — the iframe page owns its scroll track), or import the module directly into any page. Dev asset viewer: index.html?viewer, isolated assets via ?asset=market|community-center|street-lamp|base-world. Export GLBs: ?viewer → "export GLBs" button (or window.City3D.exportAllAssets(true)).
OVMG platform.html wiring: the community pin section computes per-phase m (0..1) and calls setLift(kinds[i], m); kinds = [communityCenter, market, streetLamps] matching the three text steps; 2D layered images remain in the DOM as no-WebGL fallback.
